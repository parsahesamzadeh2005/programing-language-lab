# آزمایشگاه زبان‌های برنامه‌نویسی

این مخزن (repository) شامل تمرین‌ها و مثال‌های کلاسی درس آزمایشگاه زبان‌های برنامه‌نویسی به زبان **پایتون** است. مطالب به‌صورت جلسه‌بندی‌شده سازماندهی شده‌اند و هر جلسه شامل دو پوشه است:

- `class/` — مثال‌ها و کدهای حل‌شده در کلاس
- `homework/` — تمرین‌های خانگی

## ساختار پوشه‌ها

```
programing-language-lab/
├── session_1/
│   └── homework/
│       ├── math_operations.py   # چهار عمل اصلی روی دو عدد
│       └── tax_calculator.py     # محاسبه مالیات و حقوق خالص
└── session_2/
    ├── class/
    │   ├── 1.py
    │   ├── 2.py
    │   └── 3.py
    └── homework/
        ├── 1_even_odd_sign.py    # بررسی زوج/فرد و علامت عدد
        ├── 2_cinema_ticket.py    # قیمت بلیت سینما بر اساس سن
        └── 3_leap_year.py        # تشخیص سال کبیسه
```

## نحوه اجرا

هر فایل به‌صورت مستقل اجرا می‌شود. کافی است پایتون را روی سیستم خود نصب داشته باشید:

```bash
python session_2/homework/3_leap_year.py
```

برخی از برنامه‌ها از کاربر ورودی می‌گیرند، پس پس از اجرا مقدار درخواست‌شده را در ترمینال وارد کنید.
